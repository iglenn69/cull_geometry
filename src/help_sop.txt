= Cull Geometry =

#type: node
#context: sop
#internal: cull_geometry
#icon: SOP/blast

"""Culls points or primitives outside a camera's view frustum."""

With __Cull Occluded__, geometry hidden behind other geometry (for example
terrain behind a ridge) is culled as well.

Works with OBJ cameras and USD cameras (from LOP nodes), so the same node can
be used inside a Geometry object or inside a SOP Modify / SOP Create LOP.

Culled elements are first placed in the `cull_candidates` group. The Output
menu then deletes them, deletes the visible elements instead, or keeps
everything and leaves the group for downstream nodes.

@inputs

Geometry to Cull:
    Points, primitives, packed primitives or a heightfield.

Occluders (optional):
    Extra geometry that can block the camera's view, used by __Cull
    Occluded__ when __Occluders__ includes the second input.

@parameters

Camera:
    #id: camera
    One of:
    * An OBJ camera: `/obj/cam1`
    * A LOP node: `/stage/camera1` (prim from __Camera Prim (USD)__)
    * A LOP node followed by a prim path: `/stage/camera1/cameras/camera1`
    * A USD prim path, when inside SOP Modify: `/cameras/camera1`
    * Empty, when inside SOP Modify: the first camera on its input stage.

Camera Prim (USD):
    #id: cam_primpath
    USD camera prim used when __Camera__ points at a LOP node.

Input Packed Geometry:
    #id: is_packed
    Cull whole packed primitives using their top-level bounds (or centroid)
    without unpacking them. Forces primitive mode and ignores connectivity.

Input Heightfield:
    #id: is_heightfield
    Treat the input as a heightfield. Each voxel is tested at its terrain
    surface position (base plane plus height), so raised terrain is culled
    correctly. See __Heightfield Output__. Only the first `height` layer is
    used; for tiled heightfields, run the node in a For-Each loop per tile.

Run over Primitives:
    #id: run_over_prims
    Off tests and culls points. On tests and culls primitives.

Use Connectivity:
    #id: use_connectivity
    Keep a connected piece if any of its elements is visible.

Primitive Test:
    #id: bound_test
    Centroid tests the primitive position (heightfields: the voxel's surface
    point) only. Bounding Box keeps a primitive (heightfields: a voxel) if any
    part of its bounds touches the frustum.

Z Near:
    #id: znear
    Elements closer to the camera are culled.

Z Far:
    #id: zfar
    Elements further from the camera are culled.

Overscan:
    #id: overscan
    Pads the frustum relative to the screen size. `0.1` adds 10% on each side.

Viewing Range:
    #id: view_range
    Current Frame:
        Re-culls every frame (time dependent).
    Single Frame:
        Culls once using the camera at __Frame__.
    Frame Range:
        Keeps anything visible at any frame of __Start/End/Inc__. The result
        does not change over time.

Cull Occluded:
    #id: occlusion
    Also cull elements inside the frustum that the camera cannot see because
    other geometry blocks them, such as terrain behind a ridge. A ray is cast
    from each element (heightfields: each voxel's surface) to the camera.
    Bounding Box casts from the centre and the 8 corners, so a primitive
    that only peeks over an occluder is kept. A primitive never occludes
    itself. With Frame Range, an element must be in view and unblocked on
    the same frame.

Occluders:
    #id: occluder_source
    Geometry that can block the view: the input itself, the second input,
    or both. Packed primitives are used directly without unpacking.

Occlusion Bias:
    #id: occlusion_bias
    Distance, in scene units, that each ray starts away from its surface.
    Raise it if surfaces wrongly hide themselves; lower it if thin occluders
    are missed.

Heightfield Occluder LOD:
    #id: occluder_lod
    Resolution of the polygon terrain used as the occluder (1 = every voxel).
    Lower values are much faster and usually nearly as accurate.

Output:
    #id: output_mode
    Delete Outside Frustum, Delete Inside Frustum, or Group Only
    (`cull_candidates` group; for heightfields, a `cull_candidates` layer
    where 1 = culled, leaving height and mask untouched).

Heightfield Output:
    #id: hf_output
    Mask Layer:
        Replaces the `mask` layer with visibility (1 = visible, inverted for
        Delete Inside).
    Crop to Visible:
        Crops the heightfield to the bounding rectangle of the visible region
        and removes it entirely if nothing is visible. A heightfield can only
        be cropped to a rectangle aligned with its grid, so when the camera
        looks diagonally across the terrain the rectangle still contains
        hidden voxels; the `mask` layer is replaced with visibility (1 =
        visible) to mark the exact visible region inside it. Applies to Delete
        Outside only; Delete Inside always writes the mask.
